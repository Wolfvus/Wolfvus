# Omar Guerrero

I build products and automate the boring stuff.

## [Padelo](https://github.com/Wolfvus/padelo) · Who moved up after the match?

Record a doubles match and Padelo updates all four players’ Elo ratings. Players can check the rankings and match history from an installable web app. Built with Go, PostgreSQL, and vanilla JavaScript. [See the rankings screen](https://github.com/Wolfvus/padelo/blob/main/docs/images/rankings.png).

## [GoHealth](https://github.com/Wolfvus/gohealth) · How has my sleep changed?

GoHealth brings Fitbit and Google Health exports into a local PostgreSQL database. A TypeScript CLI handles the import, and a Grafana dashboard lets you explore sleep, heart rate, and activity over time.

## [SuperScreenshot](https://github.com/Wolfvus/superscreenshot) · How does this page look on a phone?

My fork of [mangurk/superscreenshot](https://github.com/mangurk/superscreenshot) adds responsive device previews and automatic capture cleanup to a Chrome extension. Screenshots stay on the device.

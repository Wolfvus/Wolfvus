# Omar Guerrero

I build software that gives people control over their data. These are a few projects I share publicly.

[Website](https://omarguerrerox.com/en/) · [Español](https://github.com/Wolfvus/Wolfvus/blob/main/README.es.md)

## Selected work

- [GoHealth](https://github.com/Wolfvus/gohealth) imports health records into a local PostgreSQL database so you can explore them in Grafana.
- [Padelo](https://github.com/Wolfvus/padelo) tracks doubles rankings. Its Go service records each match and updates all four players’ ratings in a single transaction.
- [SuperScreenshot](https://github.com/Wolfvus/superscreenshot) is my fork of a Chrome extension for on-device capture. I added mobile viewport emulation and automatic cleanup of temporary screenshots.

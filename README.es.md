# Omar Guerrero

Desarrollo software para que las personas tengan el control de sus datos. Estos son algunos de los proyectos que comparto en público.

[Sitio web](https://omarguerrerox.com/) · [English](https://github.com/Wolfvus)

## Proyectos seleccionados

- [GoHealth](https://github.com/Wolfvus/gohealth) importa datos de salud a una base local de PostgreSQL para que puedas explorarlos en Grafana.
- [Padelo](https://github.com/Wolfvus/padelo) lleva la clasificación de pádel en dobles. El servicio en Go registra cada partido y actualiza la puntuación de los cuatro jugadores en una sola transacción.
- [SuperScreenshot](https://github.com/Wolfvus/superscreenshot) es mi versión de una extensión de Chrome que guarda las capturas en el dispositivo. Agregué la emulación de pantallas móviles y el borrado automático de las capturas temporales.
